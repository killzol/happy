КАК ПОЛЬЗОВАТЬСЯ САЙТОМ
========================

Структура (страницы открываются в этом порядке):
  index.html    + style1.css     + script1.js     — пароль
  quiz.html     + style-quiz.css + script-quiz.js  — три шуточных вопроса
  intro.html    + style-intro.css+ script-intro.js — "что дальше" перед галереей
  gallery.html  + style2.css     + script2.js      — галерея с поиском по дате
  love.html     + style-love.css + script-love.js  — тёплое письмо после галереи
  postcard.html + style4.css     + script4.js      — открытка с музыкой

Открывать сайт нужно начиная с index.html (двойной клик или через любой
локальный сервер). Пароль: 13.07.2025


1. ПАРОЛЬ
---------
Задан в script1.js в строке:
    var CORRECT_PASSWORD = "13.07.2025";
Подсказку "год — Лахта" можно поменять в index.html (тег <p class="hint">).
Даётся 5 попыток, после чего форма блокируется до перезагрузки страницы.


2. КВИЗ (quiz.html)
--------------------
Три шага, идут друг за другом на одной странице:

  Шаг 1 — "Ты любишь меня?" Кнопка "Нет" с каждым нажатием уменьшается
  и убегает в случайное место, а кнопка "Да" — растёт. Дальше пускает
  только "Да". Поменять фразы, которые всплывают при нажатии "Нет" —
  массив teasePhrases в script-quiz.js.

  Шаг 2 — "У кого сегодня праздник?" Любой ответ ведёт дальше
  (правильного/неправильного варианта тут нет специально).

  Шаг 3 — "Как я тебя чаще всего называю?" 5 вариантов, верный —
  "Кисуня". Если промахнуться — появится шутливое сообщение и можно
  пробовать ещё раз. Список вариантов — прямо в quiz.html
  (#nicknameButtons), правильный помечен атрибутом data-correct="true".

После верного ответа на 3-й шаг — переход на intro.html.


3. "ЧТО ДАЛЬШЕ" (intro.html)
------------------------------
Короткая страница-тизер с тремя пунктами о том, что ждёт впереди
(галерея, сюрприз-сердце внутри неё, открытка в конце). Текст пунктов —
прямо в intro.html, в блоке <ul class="intro-list">. Кнопка "Идём!"
ведёт в gallery.html.


4. ГАЛЕРЕЯ (gallery.html)
--------------------------
Теперь галерея устроена иначе: на заднем фоне медленно "плавают"
размытые копии фото (создают живую атмосферу), а когда ты вводишь
дату в поиск (или нажимаешь дату в справочнике справа сверху) —
нужные кадры плавно "всплывают" чёткими карточками по центру экрана.

Все фото и видео описаны в script2.js в массиве PHOTOS в самом начале
файла:

    var PHOTOS = [
      { id: 1, dates: ["12.02.2023"], type: "image" },
      { id: 4, dates: ["08.03.2023"], type: "video" },
      ...
    ];

Чтобы вставить СВОЮ ФОТОГРАФИЮ — добавь поле src с путём к файлу:
    { id: 1, dates: ["12.02.2023"], type: "image", src: "photo1.jpg" }

Чтобы вставить ВИДЕО — укажи type: "video" и src с путём к файлу:
    { id: 4, dates: ["08.03.2023"], type: "video", src: "video1.mp4" }

Видео в формате .MOV (например, снятые на iPhone) тоже поддерживаются —
просто укажи src с расширением .MOV, скрипт сам подставит правильный
тип файла. Но учти: некоторые iPhone-видео используют кодек HEVC,
который не все браузеры на Windows/Android умеют проигрывать. Если
видео не воспроизводится — самый надёжный вариант: конвертировать
его в .mp4 (H.264) любым бесплатным конвертером и указать новый путь
в src.

В фоновом "живом" коллаже видео показывается лишь неподвижным
превью-кадром (это нормально, оно там просто для атмосферы). А вот в
карточке, которая всплывает по поиску даты, у видео есть настоящие
элементы управления и звук — его можно посмотреть полностью.

Если у одной фотографии несколько дат — перечисли их в массиве:
    dates: ["12.02.2023", "14.02.2023"]

Можно добавлять сколько угодно новых объектов в массив PHOTOS — просто
скопируй строку и поменяй id/dates/src. Справочник дат и фоновый
"живой" коллаж соберутся автоматически из этого же списка.

Сердце в центре галереи ведёт на новую страницу love.html (а не сразу
на открытку).


5. ПИСЬМО (love.html)
-----------------------
Тёплая страница с "печатающимся от руки" текстом и пульсирующим
сердцем на фоне из летящих лепестков. Сам текст — в самом начале
script-love.js, в переменной LOVE_TEXT (можно менять как угодно,
переносы строк делаются через \n). После того как текст допечатался,
появляется кнопка "Открыть открытку" — она ведёт на postcard.html.


6. ОТКРЫТКА (postcard.html)
----------------------------
Текст открытки — прямо в postcard.html внутри <div class="postcard-text">.
Просто замени на свои слова.

Музыка: положи файл с названием ровно "song.mp3" в ту же папку,
где лежит postcard.html. Если файл называется иначе или у него другое
расширение — поменяй путь в postcard.html:
    <source src="song.mp3" type="audio/mpeg">
Например, для mp3-файла с другим именем:
    <source src="моя_песня.mp3" type="audio/mpeg">

Важно: большинство браузеров блокируют автозапуск звука без действия
пользователя. Поэтому если музыка не начнёт играть сама — на странице
появится кнопка-подсказка, и достаточно нажать на иконку 🔈 в правом
верхнем углу.


ПРОВЕРКА
--------
Все HTML-файлы проверены на корректную вложенность тегов, все JS-файлы
проверены на синтаксис (node -c) — ошибок не найдено.
